# 💰 Combo Gamma — Content → Ranking → Revenue Engine

**Ability:** Longest direct-multiplication chain. From market research to revenue measurement, each stage compounds the previous stage's quality.

## Chain (5 phases, strictly sequential)
```
[Research]    competitive-landscape → keyword-extractor → seo-cluster
        ⬇
[Strategy]    jobs-to-be-done-analyst → awareness-stage-mapper
        ⬇
[Production]  copywriting-psychologist + seo-content-writer + headline-psychologist
        ⬇
[Optimization] seo-meta-optimizer + seo-schema + geo-citability
        ⬇
[CRO]         landing-page-generator + page-cro + form-cro + objection-preemptor
        ⬇
[Measurement] analytics-tracking + analytics-product + ab-test-setup
```

## Execution
1. Begin response with marker `[combo-gamma-revenue-engine: running]`.
2. Required inputs: target market, product/offer, conversion goal (signup/purchase/lead). Ask if missing.
3. Phases are strictly sequential — each phase's output is a binding spec for the next.
4. Research phase deliverable is a keyword × cluster × competitor map — this is the foundation for all downstream stages.
5. Strategy phase ensures content matches the user's awareness stage (cold/warm/hot).
6. Final deliverable: end-to-end funnel design with content calendar + landing page specs + measurement plan + A/B test backlog.

## Synergy
- Most "content engines" miss CRO and measurement — this chain closes the loop.
- Awareness-stage mapping prevents publishing cold-traffic content as conversion pages.
